Generates a title and content draft for the next batch of albums. Medium has no publishing API for this account (no "Integration tokens" under Settings → Security and apps), so this can't post a draft for you — copy the result into a new Medium story instead.

Import medium post

Paste a published Medium post URL to scrape it and merge new albums into the database.
Medium scraping can fail on production. Cloudflare sometimes challenges this server's own (datacenter) IP as a bot, and the fetch below will fail with an error. If that happens, run the server locally instead (uvicorn server:app --reload --port 8000, then open http://localhost:8000/admin/) — your home IP isn't challenged, and the local version of this page shows an extra "Scrape locally & push to production" button that fetches here and writes the result straight into the production database.
